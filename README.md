📜 About the Project

A complete, fan-made Arabic translation for Hollow Knight: Silksong, crafted with care to deliver an authentic experience that honors the world of the game.

Rather than translating from a single source, all in-game texts were gathered and cross-referenced from the official English, French, and Italian game files. This approach ensures the Arabic localization faithfully captures the charm of the characters, the atmosphere of the environment, and the intricate lore of the game.

✨ Features

Tri-Lingual Cross-Referenced Translation: Built by comparing the official English, French, and Italian game files for maximum accuracy and literary flair.

Zero Compatibility Issues: Designed to integrate cleanly with the game without breaking files or causing conflicts.

Ultra-Lightweight: Everything is compacted into a tiny ~1.5 MB .exe installer.

One-Click Setup: No manual file extraction or complicated patching steps required.
